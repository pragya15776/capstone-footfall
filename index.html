Which hours lose the most shoppers?

A pipeline on 12 stores over 90 days: raw files cleaned in Databricks, loaded into Snowflake, then queried for conversion rate by hour.

Conversion is lowest between 2 pm and 4 pm.

Bills per visitor, sensor-verified hours only. Bars start at zero, so the gap between hours is small but consistent.

Data quality choices

  • Hours where the sensor was offline or returned an error have no footfall value, so they are left out of conversion rates instead of counted as zero.
  • The Snowflake load can be re-run safely: files already loaded are skipped.
Stack: Databricks (PySpark), Snowflake (SQL). Code and screenshots are in the GitHub repository for this project.
